# Task Completion Workflow

1.  **Implement Changes:** Modify code in `src/`.
2.  **Linting:** Always run `npm run lint` to ensure code style compliance.
3.  **Manual Verification:** Since this is a GUI app, changes usually require starting the app (`npm start` or `npm run dev`) to verify behavior visually.
4.  **Tests:** There are no automated tests (unit/e2e) currently configured in `package.json` scripts. Reliability relies on manual testing and linting.
