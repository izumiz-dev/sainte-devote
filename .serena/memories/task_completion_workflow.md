# Task Completion Workflow

1.  **Code Changes:** Implement the requested feature or fix.
2.  **Linting:** Always run `pnpm lint` to ensure code style compliance.
3.  **Manual Verification:** Since this is a GUI app, changes usually require starting the app (`pnpm start` or `pnpm dev`) to verify behavior visually.
4.  **Documentation:** Update relevant documentation if necessary.
